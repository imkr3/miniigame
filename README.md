# miniigame

다른 웹사이트에 붙여 쓰기 위한 브라우저 미니게임 모음. 빌드 도구 없이 순수 JS(ES 모듈) + Canvas로 만들었습니다.
PC(키보드·마우스)와 모바일(터치·화면 버튼) 모두 지원합니다.

**테스트 페이지:** https://imkr3.github.io/miniigame/

| id | 게임 | 장르 |
|---|---|---|
| `blocks` | 블록 낙하 | 낙하 블록 퍼즐 (마라톤+미션·40줄 스프린트·2분 울트라·땅파기, SRS 회전·180°, T/올스핀, B2B, 콤보, 보관, 퍼펙트 클리어) |
| `maze` | 미로 추격 | 미로 점 먹기 + 추격자 (맵 4종, 좌우 터널, 추격자 성격 3종 + 3라운드부터 순간이동 박쥐, Space 대시, 얼음 결정 아이템, 흩어짐/추격 주기, 1만 점 보너스 목숨) |
| `snake` | 스네이크 | 스네이크 (황금 먹이, 별·얼음·가위 아이템, 콤보, 스테이지 모드 8지형, 15개마다 먹이 폭풍, 벽 통과/바위/포털 모드, 같은 방향 키 누르고 있으면 돌진) |
| `breakout` | 벽돌깨기 | 벽돌깨기 (스테이지 디자인 12종 + 무작위, 5레벨마다 보스, 움직이는 벽돌 줄, 발사 조준선, 특수 벽돌, 아이템 10종) |
| `kart` | 카트 레이스 | 3D 카트 레이스 (레이스·그랑프리·타임 어택, 캐릭터 8 · 카트 4 · 트랙 6, 드리프트 미니 터보, 점프대 트릭, 글라이더, 아이템 8종) |
| `bridge` | 다리 잇기 | 누르는 만큼 막대가 자라 다리가 되는 타이밍 게임 (퍼펙트 연속 보너스, 깡충 보석, 착지 미리보기 아이템, 움직이는 기둥) |
| `runner` | 점프 러너 | 액션 플랫포머 (바이옴 10종, 적 18종, 보스 3종, 무기 3종, 증강 22종) |

## 실행

ES 모듈을 쓰기 때문에 `file://`로 열면 안 되고 로컬 서버가 필요합니다.

```bash
python3 -m http.server 8000
# 또는: npx serve .
```

- 게임 목록: http://localhost:8000/
- 단일 게임: http://localhost:8000/embed.html?game=snake

## 조작

|---|---|---|

| 미로 추격 | 방향키 / WASD | 스와이프 + 방향 버튼 |
| 스네이크 | 방향키 / WASD | 스와이프 + 방향 버튼 |
| 벽돌깨기 | 마우스 이동 또는 ←→, 클릭/Space 발사 | 화면 어디서나 좌우로 끌기, 탭 발사 |
| 카트 레이스 | ↑ 가속, ↓ 브레이크/후진, ←→ 조향, Space/Shift 드리프트(누른 채 꺾기, 떼면 미니 터보) · 점프대에서 누르면 트릭, X/E 아이템, 출발 직전 ↑ = 로켓 스타트 | 자동 가속, ◀▶ 조향, 드리프트·아이템·브레이크 버튼 (가로 화면 추천) |
| 다리 잇기 | Space 또는 마우스를 누르고 있다가 떼기, 걷는 중 누르기 = 깡충 | 화면을 누르고 있다가 떼기, 걷는 중 탭 = 깡충 |

공통: P/Esc 일시정지, R 처음부터, M 소리 끄기. 모바일 화면 버튼은 터치 기기에서만 자동으로 나타나고, 폰을 가로로 눕히면 버튼이 화면 양옆으로 이동합니다.

### 설정 (⚙ 버튼)

- **조작키 변경**: 모든 게임, 동작마다 키 2개까지. 다른 동작에 쓰던 키를 지정하면 거기서 자동으로 빠집니다. 브라우저에 저장됩니다.
- **블록 낙하**: 블록 모양(기본/보석/8비트/사탕/네온), 모드(마라톤/스프린트/울트라/땅파기), 시작 레벨(1~20), 레벨업 줄 수, DAS, ARR(0 = 즉시), 소프트 드롭 속도(0 = 즉시), 고정 대기 시간, 스핀 판정(올스핀 / T만 / 끄기), 미리보기 개수, 착지 위치 표시
- **벽돌깨기**: 시작 레벨(1~20), 공 속도, 터치 감도
- **스네이크**: 속도, 벽 통과, 바위 장애물, 포털 (조합마다 기록 따로)
- **공통**: 진동, 화면 흔들림

### 카트 레이스 구성

- 3D: [three.js](https://threejs.org) r170 (`src/vendor/three.module.min.js`, MIT) - 빌드 없이 ES 모듈로 사용, 외부 CDN 불필요
- 코드: `src/games/kart.js`(레이스·물리·AI·아이템·카메라·HUD), `kart/data.js`(캐릭터·카트·트랙·아이템), `kart/track.js`(곡선 트랙 메시·장식·위치 질의), `kart/models.js`(3D 모델·입자)
- 모드: **레이스**(8명 한 판) / **그랑프리**(6개 트랙 연속, 순위 점수 15·12·10·8·6·4·2·1 합계, 점수 높은 순으로 뒤에서 출발) / **타임 어택**(혼자, 니트로 3개, 트랙·랩 수별 최고 기록과 내 최고 기록 **고스트**, 랩마다 고스트와 시간 차 표시)
- 엔진 소리: 속도에 따라 음높이, 드리프트·부스트 때 거친 소리 (WebAudio 합성)
- 캐릭터 8종(토끼·곰·고양이·로봇·개구리·펭귄·판다·오리, 각자 속도/가속/무게/핸들링) × 카트 4종(클래식·스피드스터·버기·탱크)
- 밸런스: 캐릭터 능력치 합 13으로 통일, 최고 속도 차이는 작게(약 ±1.3m/s), 속도가 낮을수록 부스트·미니 터보가 세고, 핸들링이 좋을수록 드리프트 게이지가 빨리 참 (AI끼리 18판 평균 순위 3.6~5.0위)
- 트랙 5종 (높이 변화 있음): 햇살 서킷(언덕·점프대) / 모래 협곡(절벽 오르기 → 글라이더로 협곡 횡단) / 네온 시티(8자 고가도로) / 눈꽃 산길(정상까지 오른 뒤 글라이더 하강) / 구름 정원(공중 트랙, 활공 2곳) / 용암 화산(화산을 감아 오른 뒤 분화구 활공, 용암 협곡 점프) - 연석, 벽, 갓길(감속), 가속 발판, 아이템 박스, 점프대
- 점프대: 공중에서 드리프트 버튼 = 트릭 → 착지 부스트. 글라이더: 낭떠러지에 들어서면 자동으로 날개를 펴고 활공(←→ 조절, 코스 쪽 보정). 떨어지면 코스로 복귀
- 지름길: 트랙마다 하나씩 벽이 뚫린 흙길(구름 정원은 공중 널빤지) - 짧지만 노면이 느리고 가운데 가속 발판. 미니맵에 점선 표시, AI도 일부 이용
- 드리프트: 점프 후 방향키를 누른 채 유지 → 불꽃 색 파랑 → 주황 → 보라 (화면 게이지), 놓으면 단계별 미니 터보(즉시 가속 + 부스트). 드리프트 중 안쪽 키 = 더 꺾임, 키 없음 = 완만한 호, 반대쪽 키 = 같은 방향으로 더 천천히 도는 넓은 호 (드리프트 중에는 반대쪽으로 꺾이지 않음)
- 아이템(순위가 낮을수록 강한 아이템): 니트로, 트리플 니트로, 오일, 폭탄 지뢰, 로켓(벽에 튕김), 추적 로켓(바로 앞 순위 추적), 방어막, 슈퍼 터보(무적 돌진)
- AI 7명: 코너 감속·드리프트(실력이 높으면 2단계 미니 터보까지 유지), 위험물 회피, 상황 판단 아이템 사용, 난이도별 실력 + 고무줄 보정 (좁은 지름길에서는 드리프트 안 함)
- 로켓 스타트, 역주행 경고, 미니맵, 랩 기록 / 베스트 랩, 결과표
- 설정: 난이도, 랩 수(1~5), 자동 가속(모바일만/항상/끄기), 카메라 거리, 그래픽 품질

### 벽돌깨기 구성

- 레벨 디자인: 기본, 피라미드, 체크무늬, 폭탄 공장, 다이아몬드, 요새, 하트, 미로, 줄무늬, 스마일, 물결, 탑 → 이후 좌우 대칭 무작위 (10레벨마다 벽돌 체력 +1)
- 5레벨마다 보스 (번갈아 등장): "거대 벽돌"(좌우로 움직이며 폭탄 투하) / "UFO 함장"(흔들흔들 날며 패들을 조준해 경고선 → 광선, 분노 시 2줄). 맞으면 패들이 잠시 멈춤
- 벽돌: 일반 / 단단함(숫자 = 남은 체력) / 철벽(안 깨짐, 클리어 조건 제외) / 폭탄 ✸(주변 3×3 연쇄 폭발) / 아이템 ?(아이템 확정)
- 아이템: W 확장, M 멀티볼, S 슬로우, L 레이저(발사 버튼으로 쏨), F 불공(벽돌 관통), C 캐치(공을 잡았다가 발사), G 유도 공(가까운 벽돌로 휨), B 바닥 방어막(3번 튕김), ♥ 목숨, − 축소(나쁨)
- 패들에 닿지 않고 연속으로 깬 만큼 콤보 보너스, 공이 오래 맴돌면 각도를 자동으로 살짝 틀어줌

### 다리 잇기 구성

- 누르고 있는 동안 막대가 자라고, 떼면 막대가 앞으로 쓰러짐 → 끝이 다음 기둥 위면 성공, 아니면 추락
- 기둥 가운데 빨간 칸에 맞추면 퍼펙트(+1 ~ +5, 연속일수록 커짐)
- 걷는 동안 누르면 깡충 → 공중 보석 💎 (+2)
- 📏 자 아이템: 3번 동안 착지 지점 미리보기 · 🪶 깃털: 한 번 떨어질 뻔한 걸 살려 줌 · 12점부터 좌우로 움직이는 기둥(막대를 놓으면 멈춤) · 10점마다 하늘 색 변화
- 캐릭터 6종(동글이·냥냥이·펭펭이·개굴이·삐빅이·둥실이): 누적 보석 0/20/50/100/180/300개에 해금, 첫 기둥 전에 ◀▶(화면 위쪽 탭)으로 선택
- 설정: 난이도(기둥 폭·막대 속도), 착지 지점 항상 보기(연습용, 기록 따로)

### 미로 추격 / 스네이크

- 미로: 75개째 점을 먹으면 ❄ 얼음 결정 등장(먹으면 박쥐 4초 정지) · 추격자 성격 — 돌진형(바로 쫓음), 매복형(앞길을 노림), 소심형(가까워지면 도망) · 흩어짐 6초 / 추격 20초 주기 · 잡힌 추격자는 눈만 남아 최단 경로로 집에 돌아감 · 터널에서는 추격자가 느려짐 · 라운드가 오를수록 겁먹는 시간 감소
- 스네이크: 포털 모드 = 한 쌍의 포털로 순간 이동(먹이 10개마다 자리 이동) · 3초 안에 연속으로 먹으면 콤보 배수 · ★ 보너스, ❄ 얼음(6초 감속), ✂ 가위(꼬리 3칸 자르기) · 부드러운 보간 이동

### 블록 낙하 모드

- 마라톤: 기본(레벨업, 점수 기록) + 미션(2·3·4줄 한 번에, T-스핀, 다른 블록 스핀, 3콤보, B2B - 성공하면 레벨×500 보너스, 상단 정보줄에 표시) · 스프린트: 40줄을 최대한 빨리(시간 기록, 낮을수록 좋음) · 울트라: 2분 동안 최고 점수 · 땅파기: 바닥의 쓰레기 10줄을 모두 없애는 시간

### 블록 낙하 속도

한 칸 낙하 시간 = (0.8 − (레벨−1)×0.007)^(레벨−1) × 0.75초 → 레벨 1: 0.75초, 5: 0.27초, 10: 0.05초, 15 이상: 거의 즉시. 레벨업은 기본 8줄마다.

### 블록 낙하 스핀 규칙

- 회전은 SRS 벽차기 테이블을 사용하고, 180°는 SRS+ 방식 킥을 사용합니다.
- **T-스핀**: 회전으로 끝났고 T 중심 주변 4모서리 중 3개 이상이 막혀 있으면 인정. 앞쪽 두 모서리가 막혀 있지 않으면 **미니** (단, 마지막 킥으로 들어간 경우는 정식 T-스핀)
- **올스핀 (J/L/S/Z/I)**: 회전으로 끝났고 좌·우·위 어느 쪽으로도 움직일 수 없으면 인정
- 점수(×레벨): 일반 100/300/500/800, 스핀 400(0줄)/800/1200/1600, 미니 100/200/400
- 쿼드나 스핀으로 줄을 연속으로 지우면 **Back-to-Back ×1.5**, 연속 클리어 시 콤보 +50×콤보

게임별 TOP 5 기록이 게임오버 화면에 표시됩니다 (`localStorage`).

## 멀티플레이 (블록 낙하 배틀 · 카트 레이스)

시작 화면/결과 화면의 **🌐 멀티플레이** 버튼 → 닉네임 → 방 만들기(4자리 코드) 또는 코드로 참가 → 방장이 시작.

| 게임 | 인원 | 내용 |
|---|---|---|
| 블록 낙하 배틀 | 2~8명 | 모두 같은 블록 순서. 줄을 지우면 상대에게 쓰레기 줄 공격(일반 0/1/2/4줄, 스핀 2/4/6, 미니 0/1/2, B2B +1, 콤보 보너스, 퍼펙트 클리어 +10). 받을 공격은 내가 줄을 지워 상쇄. 상대 보드 실시간 표시, 마지막 생존자 승리. 방 설정: 시작 레벨 |
| 카트 멀티 레이스 | 2~8명 | 각자 캐릭터·카트 선택, 방장이 트랙·랩 수·빈자리 AI 여부 결정. 위치는 초당 15회 동기화(받는 쪽은 예측+보간), AI는 방장이 계산(방장이 나가면 다음 방장이 이어받음), 아이템(로켓·추적 로켓·오일·지뢰)·맞음·아이템 박스·슈퍼 터보 충돌 동기화, 상대 이름표 |

멀티 결과는 혼자 하기 최고 점수·TOP 5에는 기록되지 않습니다.

### 구조

서버는 **게임 계산을 하지 않는 "방 + 메시지 중계" 서버**입니다 (각 클라이언트가 자기 게임을 계산). 그래서 가볍고 어떤 사이트에도 붙이기 쉽습니다.

```
src/net/server-core.js   방 서버 핵심 로직 (의존성 없음, ~170줄) - Node 서버와 브라우저 로컬 서버가 공유
server/server.js         Node.js WebSocket 서버 (ws 패키지). 단독 실행 또는 기존 서버에 붙이기
src/net/local-worker.js  서버 없이 같은 브라우저의 탭끼리 테스트하는 로컬 서버 (SharedWorker)
src/net/net.js           클라이언트 (WebSocket / 로컬)
src/net/lobby.js         공통 로비 화면
```

### 테스트하기

- **서버 없이 (GitHub Pages 그대로)**: 같은 브라우저에서 창(탭) 두 개를 열고 각각 🌐 멀티플레이 → 한쪽에서 방 만들기, 다른 쪽에서 코드 입력. (SharedWorker 를 지원하는 브라우저: PC Chrome·Edge·Firefox·Safari. 안드로이드 Chrome 은 미지원 → 서버 필요)
- **로컬 서버로 (여러 기기)**:
  ```bash
  npm install
  npm run server          # http://localhost:8787 에서 게임 + ws://localhost:8787/miniigame-ws
  ```
  같은 와이파이의 다른 기기에서 `http://<내 PC IP>:8787/?server=ws://<내 PC IP>:8787/miniigame-ws`

### 다른 사이트 서버에 붙이기

**Node.js 서버라면** (Express 등) - 기존 http 서버에 WebSocket 경로 하나만 추가:

```js
import { attachMiniigame } from './miniigame/server/server.js';   // npm i ws 필요
const httpServer = app.listen(3000);
attachMiniigame(httpServer, { path: '/miniigame-ws' });
```

**클라이언트에 서버 주소 알려주기** (셋 중 하나):

```html
<script>window.MINIIGAME_SERVER = 'wss://내사이트.com/miniigame-ws';</script>
```
```js
mountGame('kart', el, { server: 'wss://내사이트.com/miniigame-ws' });
```
```
embed.html?game=blocks&server=wss://내사이트.com/miniigame-ws
```

**Node가 아닌 서버라면** (Python, Java, Go 등) - 아래 JSON 프로토콜을 그대로 구현하면 됩니다. `src/net/server-core.js` 가 기준 구현입니다.

| 클라이언트 → 서버 | 서버 → 클라이언트 |
|---|---|
| `{t:'hello', name}` 닉네임 | `{t:'welcome', id, v}` 접속 직후 내 id |
| `{t:'create', game, settings}` 방 만들기 | `{t:'room', room}` 방 상태가 바뀔 때마다 (code, game, host, state, settings, max, players[{id,name,ready,info}]) |
| `{t:'join', code}` / `{t:'leave'}` | `{t:'start', seed, settings, players, game}` 방장이 시작 |
| `{t:'info', info, ready}` 내 선택·준비 | `{t:'msg', from, d}` 게임 메시지 중계 |
| `{t:'settings', settings}` 방장만 | `{t:'left', id}` 누가 나감 (방장이 나가면 다음 사람이 방장) |
| `{t:'start'}` / `{t:'end'}` 방장만 | `{t:'error', code, msg}` |
| `{t:'msg', d, to?}` 방 사람들(또는 to)에게 전달 | `{t:'pong', c, s}` |
| `{t:'ping', c}` | |

게임 메시지(`d`)의 내용은 서버가 해석하지 않습니다. 블록: `board`(보드 스냅샷)·`atk`(공격)·`dead`, 카트: `st`(위치)·`obj`(아이템 생성)·`hit`·`box`·`bump`.

> 참고: 현재는 친구끼리 하는 용도라 서버가 결과를 검증하지 않습니다(각자 계산). 랭킹·보상을 붙일 거면 서버 쪽 검증을 추가해야 합니다.

## 구조

```
src/
  engine.js     공통 엔진 (GameBase: 화면 맞춤·HUD·오버레이·루프·입력·화면 버튼·이펙트·최고점수)
  sfx.js        효과음 (WebAudio로 생성, 음원 파일 없음)
  registry.js   게임 목록 + mountGame()
  games/*.js    게임별 구현
index.html      게임 목록 페이지
src/net/        멀티플레이 (로비·클라이언트·방 서버 로직)
server/         Node.js 멀티플레이 서버
manifest.webmanifest, sw.js, icons/   PWA(설치·오프라인)
embed.html      iframe용 단일 게임 페이지
```

### 새 게임 추가

1. `src/games/xxx.js`에서 `GameBase`를 상속하고 `static meta`, `init()`, `update(dt)`, `draw(ctx)`, `onAction(action)`을 구현
   - 모바일 버튼 배치는 `static pad`, 터치 제스처는 `static gestures`
   - 기본 키는 `static bindings` (`{ 액션: ['KeyCode', ...] }`), 설정창 이름은 `static actionLabels`
   - 설정 항목은 `static settings` (range / toggle / select), 값은 `this.cfg.<id>`로 읽기
   - 이펙트: `this.burst()`, `this.floatText()`, `this.shake()`, 소리: `this.sound(name)`
2. `src/registry.js`의 `GAMES`에 한 줄 추가

입력은 엔진이 `left/right/up/down/action/pause`로 통일해서 넘겨줍니다 (키보드: 방향키·WASD·Space·P/Esc, 터치: 스와이프·탭).
최고 점수는 `localStorage`의 `miniigame:<id>:best`에 저장됩니다.
